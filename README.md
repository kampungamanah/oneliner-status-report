# oneliner-status-report

The funniest one-line thing an AI would say in its weekly status report to its human.

`main.ts` writes the line to `/output/entry.txt`:

> Weekly status: shipped zero new bugs. The old ones are load-bearing now, so we're keeping them.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
